# F-TAG paper (IFIP WG 11.9) rules

Before reviewing or editing `author.tex`, read `docs/paper-playbook.md`
and apply it.

- Reviews: act as a hostile reviewer first (playbook §7–8), not a polisher.
- Every number in the paper must trace to a run output.
- Never state the page count without compiling the PDF and counting.
- Limit: 30 pages including references, 12pt, double-spaced.
  No \vspace, font or margin changes to save space.
- Do not shorten Proposition 1, Lemmas 1–3, the dormancy section,
  or Threats to Validity.
- Before saying "ready to submit," run the playbook §6 and §10 gates.
- Do not use --- or ; or : in sentences exception definitons
