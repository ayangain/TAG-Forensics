\title{F-TAG: Forensic Temporal Attack Graphs for Evidence-Resilient Network Investigation}

\author{Ayan Gain$^{1}$ \and Mridul Sankar Barik$^{1}$ \\
Jadavpur University, Kolkata, India \\
\texttt{ayan.gain2010@gmail.com, mridulsankar.barik@jadavpuruniversity.in}}

\maketitle

\begin{abstract}
Modern network forensics must reconstruct multi-step attack sequences from digital evidence that is incomplete, prone to accidental logging failure, and vulnerable to deliberate anti-forensic tampering. Traditional evidence graphs stall when records are missing, while static attack graphs ignore time-varying configurations and admit physically impossible sequence reconstructions. We investigate whether temporally evolving network topologies can serve as strict structural constraints for retrospective forensic analysis. We formalize Forensic Temporal Attack Graphs (F-TAG), which bind temporal reachability directly to physical graph edges and enforce chronological consistency during traversal. We derive the Forensic Window of Compromise (FWoC) to bound intrusion timelines by intersecting surviving evidence with the topological attack corridor (TAC), proving conditional soundness under contiguous execution while characterizing its breakdown under adversarial dormancy. To distinguish deliberate log wiping from routine operational loss, we formulate the Bayesian Anti-Forensics Confidence ($AF_{conf}$) metric based on host-level privilege metadata. Evaluating across DARPA LLDOS benchmarks and synthetic enterprise topologies up to 100 hosts shows that F-TAG eliminates timeless path assembly and detects timestamp falsifications that static attack graphs structurally miss. FWoC bounds achieve 100\% containment under contiguous execution, while $AF_{conf}$ achieves an Area Under the Curve (AUC) of 0.80 under administrative privilege-targeting, falling to 0.56 under unbiased wiping, which exposes the fundamental reliance of binary privilege models on attacker operational bias.

\textbf{Keywords:} Network Forensics, Temporal Attack Graphs, Anti-Forensics, Bayesian Analysis
\end{abstract}

\section{Introduction}\label{sec:introduction}

Imagine an investigator responding to a breach whose only trace is an IDS alert on a database while upstream web logs are lost. Did the attacker exploit a vulnerability patched last week, or an active flaw? Was the log deliberately wiped? Without answers, investigations stall~\cite{khan2022digital}. Two tangled challenges emerge. Surviving evidence may be missing or falsified, and candidate attack sequences must be validated against how the network physically evolved over time.

Existing tools solve one problem or the other, never both. Evidence graphs~\cite{wang2008evidence} reconstruct causal chains directly from logs and alerts. They work well when evidence is complete, but the chain simply breaks wherever a log is wiped. Conversely, static attack graphs~\cite{1004377,Lallie2020} are often used to bridge these gaps by correlating alerts against known vulnerability paths~\cite{10.1145/586110.586144,ning2004building}. While static attack graphs successfully map every path the network has ever permitted, they collapse that history into a single timeless snapshot, offering no notion of when each path was actually usable.

\textbf{Why a static attack graph is not enough.} A static attack graph combines assets and vulnerabilities from a single network snapshot. It evaluates reachability, whereas forensics must evaluate time and order.

For example, if a static attack graph built on Monday ignores a Tuesday patch, it accepts impossible Wednesday alerts through closed routes. Across multi-step attacks, it can stitch a Week~1 exploit to a Week~3 alert via a server patched in Week~2. The result is a ``Frankenstein path''\footnote{An attack sequence assembled from attack steps that were individually valid but at non-overlapping points in time, making the combined path physically impossible.}---an attack sequence physically impossible in chronological order despite each step having once been permitted.

This lack of temporal enforcement causes three forensic failures. \textbf{Temporal feasibility errors} occur when an edge did not exist when required by the preceding hop. \textbf{Topology transition errors} occur when vulnerabilities disappear mid-attack. \textbf{Evidence stitching errors} occur when individual alerts match static edges, but no chronological sequence can accommodate all alerts together. In all cases, the graph fails to verify if a multi-step sequence was ever physically possible.

Temporal attack graphs (TAGs)~\cite{Gain2023} resolve the first two failure modes structurally, by requiring that the time window in which each hop is used never precede the time window used by the hop before it. This is the key difference from simply stamping timestamps onto static edges. A TAG enforces the ordering constraint jointly across the entire attack path during traversal, not edge by edge after the fact, so a Frankenstein path is never assembled in the first place. What a TAG alone cannot resolve is the third failure mode, because it lacks mechanisms to inject observed evidence against that structure or reason over gaps where evidence is missing. Forensic investigation requires precisely that capability---injecting retrospective evidence as a structural constraint over time-aware topologies to draw sound conclusions under incomplete or contradictory logs.

F-TAG closes this gap. The relevant forensic object is not a static path, but a temporally feasible attack sequence constrained by surviving evidence. Rather than building attack graphs bottom-up from fragile logs, F-TAG enumerates temporally feasible paths from network topology alone and constrains them retrospectively with observed alerts (Figure~\ref{fig:motivating-example}). This rejects temporally impossible evidence outright while bounding unobserved intrusion spans through the Forensic Window of Compromise.

This paper makes the following contributions:
\begin{enumerate}
    \item Formalizing temporal forensic reconstruction by injecting observed evidence (IDS alerts and system logs) as strict structural constraints upon time-aware network topologies.
    \item Deriving the Forensic Window of Compromise (FWoC) to establish conditional soundness guarantees that bound unobserved attacker actions when evidence is missing.
    \item Demonstrating temporal contradiction detection to natively identify and filter false-positive alerts and falsified evidence where methods that rely on static attack graphs fail.
    \item Introducing Anti-Forensics Confidence ($AF_{conf}$), a Bayesian metric to quantify the likelihood of deliberate log-wiping versus routine evidence loss.
    \item Validating timeline containment, chokepoint ranking invariance, and falsification filtering across DARPA LLDOS benchmarks~\cite{haines2001extending,darpa2000lldos} and synthetic enterprise topologies up to 100 hosts.
\end{enumerate}

\section{Related Work}\label{sec:related-work}

\subsection{Attack Graphs and Alert Correlation}\label{sec:static-ag}

Attack graphs proactively map vulnerability chains~\cite{Noel2018,Lallie2020}. Formally, a static attack graph $G = (E \cup C, R_{r} \cup R_{i})$ consists of exploits ($E$), conditions ($C$), prerequisites ($R_{r}$), and implications ($R_{i}$) in MulVAL~\cite{mulval,6263942}. Alert correlation matches IDS alerts against these relationships~\cite{10.1145/586110.586144,ning2004building,husak2019survey}. Because $G$ lacks time, it cannot model patches, configuration changes, or causal order, leading correlation engines to construct backward-time causal chains---the core limitation motivating F-TAG.

\subsection{Evidence Graphs and Network Forensics}

Evidence graphs~\cite{wang2008evidence,he2016network} structure observed digital evidence into graphs for investigative traversal, but stall when logs are missing. Approaches combining them with attack graphs typically use probabilistic inference (Bayesian networks, Markov models) or topological causality to estimate missing events or detect inconsistencies~\cite{liu2012using,zhang2015detecting,Frigault2017}, though static representations lack time-varying topological boundaries. At the host level, provenance graphs (e.g., HOLMES~\cite{milajerdi2019holmes}) reconstruct intra-host execution flows across system calls; F-TAG complements them by enforcing macro-network temporal topological boundaries across multi-host network evolutions.
  
\subsection{Temporal and Dynamic Network Security}

Dynamic assessment methods recognize that temporal constraints fundamentally change path structures~\cite{Holme,Casteigts2012}, motivating temporal risk variance analysis~\cite{Awan2016}, dynamic attack surface evaluation~\cite{ENOCH2019102448}, and Temporal Attack Graph (TAG) formalisms~\cite{Gain2023}. 

TAG formalisms~\cite{Gain2023} represent temporal topology as discrete snapshot sequences to assess future reachability, but lack mechanisms for retrospective forensic evidence. F-TAG bridges this gap by transforming temporal topologies into an evidence-constrained forensic model. \section{Foundational Theory}\label{sec:theory}

To model enterprise network forensics without state-space explosion or causal ambiguity, F-TAG formalizes how time-varying physical topologies constrain observed digital evidence.

\subsection{Definition 1: Forensic Temporal Attack Graph (F-TAG)}\label{sec:def1}

F-TAG executes a reconstruction phase to collapse the discrete snapshots of a TAG into a unified structure where each edge $e$ carries a set of active time windows $\mathcal{W}(e) \subseteq \{0, 1, \dots, \tau-1\}$, where $\tau$ denotes the total number of discrete time windows spanning the observation period (e.g., $\tau = 4$ for a four-week investigation). Throughout this paper, F-TAG operates at the host level, i.e intermediate logical deduction states are collapsed into direct host-to-host transitions, so each vertex in $V_{all}$ corresponds to a physical network host. This representation captures the physical reality that vulnerability exploitation paths between hosts appear and disappear over time window as configurations change, patches are applied, and firewall rules are modified, without redundant duplication of shared topology across time windows.

\textbf{Definition 1 (Forensic Temporal Attack Graph).} Formally, Forensic Temporal Attack Graph (F-TAG) is defined as:
\begin{equation}
\mathcal{G}^a_{unified} = \left(V_{all},\ E_{all},\ \mathcal{W}\right)
\end{equation}
where $V_{all} = \bigcup_{t=0}^{\tau-1} V_t$ is the cumulative set of all vertices, $E_{all} = \bigcup_{t=0}^{\tau-1} E_t$ is the cumulative set of all directed attack edges, and $\mathcal{W}: E_{all} \to 2^{\{0, 1, \dots, \tau-1\}}$ maps each edge to the set of discrete time windows in which the vulnerability it represents was present and exploitable (i.e., not yet patched or revoked). The notation $2^{\{0,1,\dots,\tau-1\}}$ denotes the power set of all time indices, meaning an edge may be active in any subset of time windows, including non-contiguous ones such as $\{0, 3\}$.

\paragraph{Physical Walkthrough Example.} 
Consider an investigation spanning four discrete weeks (denoted $w_0$ through $w_3$) with time indices $\{0, 1, 2, 3\}$. Suppose directed edge $e$ represents the exploitation of a critical web vulnerability.
\begin{enumerate}
    \item In Week~0 ($w_0$), the server is unpatched. An attacker can exploit the vulnerability, so Week~0 is active, with $0 \in \mathcal{W}(e)$.
    \item In Week~1 ($w_1$), administrators apply a vendor patch, closing the vulnerability, yielding $1 \notin \mathcal{W}(e)$.
    \item In Week~2 ($w_2$), the system remains patched, meaning $2 \notin \mathcal{W}(e)$.
    \item In Week~3 ($w_3$), an IT rollback accidentally restores an unpatched disk image, reopening the flaw, so $3 \in \mathcal{W}(e)$.
\end{enumerate}
Under F-TAG, the edge lifespan is simply $\mathcal{W}(e) = \{0, 3\}$, meaning traversal was physically possible only during Week~0 or Week~3. An IDS alert claiming exploitation during Week~1 or Week~2 is an immediate structural contradiction. Encoding active intervals directly on edges captures the full temporal topology compactly without storing per-window graph snapshots.

\subsection{Definition 2: Forensic Temporal Attack Path}\label{sec:def2}

\textbf{Definition 2.} A Forensic Temporal Attack Path $p^f_{ij}$ from host $i$ to host $j$ is a sequence of hops $\langle (e_0, \sigma_0), (e_1, \sigma_1), \dots, (e_{\eta-1}, \sigma_{\eta-1}) \rangle$. Here $k \in \{0, \dots, \eta-1\}$ is the hop index within the attack path, $\sigma_k \in \{0, 1, \dots, \tau-1\}$ is an integer that maps hop $k$ to a time window index in the F-TAG, and $w_{\sigma_k}$ is the F-TAG network snapshot at that index. Concretely, $\sigma_k = j$ means hop $k$ was executed during time window $w_j$ of the F-TAG, i.e., the edge $e_k$ must have been active in the network snapshot $w_j$. This sequence must satisfy three strict constraints:
\begin{enumerate}
    \item \textbf{Existence Constraint:} Each edge $e_k$ must be traversed in a time window where it was actually active, i.e., $\sigma_k \in \mathcal{W}(e_k)$. This ensures the exploitation path physically existed at the time it was used.
    \item \textbf{Chronological Constraint:} The time window sequence is strictly non-decreasing: $\sigma_0 \le \sigma_1 \le \dots \le \sigma_{\eta-1}$, ensuring the attacker cannot travel backward in time.
    \item \textbf{Evidence Constraint:} If an IDS alert or log entry was observed at time window $w_t$, then $w_t$ must fall within the time span $[\sigma_0, \sigma_{\eta-1}]$ of the path. If no overlap exists between the observed evidence timestamps and the path's time span, the path is rejected as a structural contradiction.
\end{enumerate}

Because each edge carries its active window set $\mathcal{W}(e)$ in a unified structure, these three constraints are evaluated jointly during traversal---preventing backward-time loops and rejecting historically impossible narratives to ensure every path is physically realizable.

\subsection{Definition 3: Temporal Attack Corridor (TAC)}\label{sec:tac}

\textbf{Definition 3 (Temporal Attack Corridor).} For a structural candidate attack path $p = \langle e_0, e_1, \dots, e_{H-1} \rangle$ between host $i$ and host $j$, let $\Sigma(p) = \{ \sigma \in \prod_{k=0}^{H-1} \mathcal{W}(e_k) : \sigma_0 \le \sigma_1 \le \dots \le \sigma_{H-1} \}$ denote the set of all temporally feasible execution sequences. The Temporal Attack Corridor (TAC) is the bounding span of discrete time windows across all feasible temporal executions:
\begin{equation}\label{eq:tac}
\text{TAC}(p) = \left[ \min_{\sigma \in \Sigma(p)} \sigma_0,\;\;\max_{\sigma \in \Sigma(p)} \sigma_{H-1} \right]
\end{equation}
Because $\text{TAC}(p)$ is derived exclusively from the network's topological and configuration history $\{\mathcal{W}(e_k)\}$, an investigator computes it directly from the proactive F-TAG without knowledge of actual intrusion times. For any realized attack execution $\sigma^* \in \Sigma(p)$, the true compromise window $[\sigma_0^*, \sigma_{H-1}^*]$ is structurally guaranteed to satisfy $\sigma_0^* \ge \min_{\sigma \in \Sigma(p)} \sigma_0$ and $\sigma_{H-1}^* \le \max_{\sigma \in \Sigma(p)} \sigma_{H-1}$, ensuring $[\sigma_0^*, \sigma_{H-1}^*] \subseteq \text{TAC}(p)$ by topological validity.

\subsection{Path Enumeration Algorithm}\label{sec:enumeration}

Given a suspect entry host $i$ (such as an external web server) and a target asset $j$ (such as an internal database), a forensic investigator must discover all structurally feasible attack paths between them. Algorithm~\ref{alg:enumerate} solves this by executing a time-constrained depth-first search over the unified graph $\mathcal{G}^a_{unified}$.

\paragraph{Computational Intractability of Static Filtering.}
Generating paths on a static attack graph and filtering Frankenstein paths ex post facto is computationally intractable, as simple paths scale with $O(k_{max}^{H_{max}})$, where $k_{max} = \max_{v} d_{out}(v)$ is the maximum node out-degree and $H_{max}$ is the search depth limit. By enforcing $\sigma \ge \sigma_{min}$ on the fly during traversal, Algorithm~\ref{alg:enumerate} prunes temporally invalid branches, reducing the effective branching factor to $k_{eff} \ll k_{max}$. In structured enterprise architectures, cross-tier firewalls bound lateral movement ($H \le 5$); setting $H_{max} \ge 5$ (evaluated up to $H_{max} = 15$) ensures no feasible path is missed while enforcing a finite search bound.

\paragraph{Guaranteed Completeness.}
Because pruning discards only backward-time transitions ($\sigma < \sigma_{min}$), no chronologically feasible path is skipped. Algorithm~\ref{alg:enumerate} is mathematically guaranteed to recover every valid temporal path of length $\le H_{max}$ between host $i$ and host $j$.

\begin{algorithm}[t]
\caption{Temporal Path Enumeration ($Q^a_{ij}$)}
\label{alg:enumerate}
\footnotesize
\begin{algorithmic}[1]
\REQUIRE F-TAG $\mathcal{G}^a$, source node $i$, target node $j$, max hops $H_{max}$
\ENSURE Set of all valid temporal attack paths $\mathcal{P}_{ij}$
\STATE $\mathcal{P}_{ij} \gets \emptyset$
\STATE $\text{Stack} \gets \{(i, 0, \langle\rangle)\}$ \COMMENT{(node, min\_window, path)}
\WHILE{Stack $\neq \emptyset$}
    \STATE $(n_{curr}, \sigma_{min}, \text{path}) \gets \text{Stack.pop()}$
    \IF{$n_{curr} = j$ \AND $|\text{path}| > 0$}
        \STATE $\mathcal{P}_{ij} \gets \mathcal{P}_{ij} \cup \{\text{TemporalPath(path)}\}$
        \STATE \textbf{continue}
    \ENDIF
    \IF{$|\text{path}| \ge H_{max}$}
        \STATE \textbf{continue}
    \ENDIF
    \FORALL{edges $e$ from $n_{curr}$}
        \FORALL{$\sigma \in \mathcal{W}(e)$ where $\sigma \ge \sigma_{min}$}
            \STATE Stack.push$(e.dst, \sigma, \text{path} \cup \{(e, \sigma)\})$
        \ENDFOR
    \ENDFOR
\ENDWHILE
\RETURN $\mathcal{P}_{ij}$
\end{algorithmic}
\end{algorithm}

\section{The F-TAG Methodology}\label{sec:methodology}

The F-TAG methodology integrates physical network evolution with observed digital evidence (such as IDS alerts, firewall logs, and authentication records) to reconstruct attack sequences when evidence is incomplete or contradictory.

\subsection{Path-Level Forensic Bounds}\label{sec:path-metrics}

When reconstructing an incident, relying solely on raw log timestamps artificially narrows the perceived timeline. Missing or wiped logs at the edges of an attack make the intrusion appear to have started later and ended earlier than it truly did. The \textbf{Forensic Window of Compromise (FWoC)} establishes the true incident timeline by intersecting what surviving evidence directly supports with what the physical network topology permits.

For an attack path $p$ with $H$ hops and $N$ observed evidence timestamps $\mathcal{E} = \{t_1, \dots, t_N\}$ mapped to discrete windows, FWoC bounds the intrusion's true start and termination by intersecting surviving evidence with the Temporal Attack Corridor (TAC):
\begin{equation}\label{eq:fwoc}
\text{FWoC}(p) = \text{TAC}(p) \;\cap\; \left[\min(\mathcal{E}) - \delta - \delta_s,\;\;\max(\mathcal{E}) + \delta + \delta_s\right]
\end{equation}
Here, $\text{TAC}(p) = [\sigma_0(p), \sigma_{\eta-1}(p)]$ defines the structural corridor, while $[\min(\mathcal{E}) - \delta - \delta_s, \max(\mathcal{E}) + \delta + \delta_s]$ expands surviving evidence timestamps by tolerance $\delta$ (clock skew and latency) and topology correction $\delta_s$. Their intersection retains only time windows that are both evidentially supported and topologically traversable.

The raw evidence span $[\min(\mathcal{E}), \max(\mathcal{E})]$ captures the earliest and latest timestamps recorded in surviving logs or alerts. To absorb network transit latency, clock synchronization errors between hosts, and the precision lost when mapping exact log timestamps into discrete time windows, the tolerance parameter $\delta$ (typically 0 or 1 time window) provides a small clock-skew margin.

The topology-aware correction term $\delta_s = \max(0, H - N)$ expands the raw evidence bounds outward.\label{sec:worst-case-bounds} This accounts for the case where up to $H - N$ unobserved contiguous actions occurred entirely before the first recorded alert or entirely after the last one. When evidence is complete ($N \ge H$), $\delta_s = 0$ and the bound tightens purely around the observed timestamps.

The TAC intersection enforces a hard boundary, ensuring that an attacker cannot exploit a vulnerability before it existed or after it was patched. For example, if $H=5$ and evidence survives for $N=2$ hops, $\delta_s=3$ expands evidence bounds outward by 3 windows, while the TAC clamps the span to physically active windows.

\textbf{Proposition 1 (FWoC Soundness).} \textit{Let $p = (e_0, \dots, e_{H-1})$ be a temporal attack path with true execution time windows $\sigma_0 \le \sigma_1 \le \dots \le \sigma_{H-1}$, and let $\mathcal{E} = \{t_1, \dots, t_N\}$ be the set of surviving evidence timestamps. Under the contiguous-execution assumption (Assumption~A):}
\begin{enumerate}
    \item \textit{\textbf{Contiguous Inter-Hop Cadence:} Each successive hop starts within at most one time window of the preceding hop, i.e.\ $\sigma_{k+1} - \sigma_k \le 1$ for all $k \in \{0, \dots, H-2\}$ (no inter-hop dormancy exceeding one window).}
    \item \textit{\textbf{Distinct Evidence Mapping:} Each of the $N$ observed evidence timestamps corresponds to a distinct hop on $p$, i.e.\ $t_i = \sigma_{k_i}$ with indices $0 \le k_1 < k_2 < \dots < k_N \le H-1$.}
\end{enumerate}
\textit{the true compromise window $[\sigma_0, \sigma_{H-1}]$ is contained in $\text{FWoC}(p)$ whenever clock skew margin $\delta \ge 0$ and $\delta_s = \max(0, H-N)$.}

\textit{Proof sketch:} Under condition~(2), exactly $N$ distinct hops are observed, leaving at most $H - N$ unobserved hops across the path. The unobserved hops preceding the earliest observed hop $k_1$ number at most $k_1 \le H - N$, and those following the latest hop $k_N$ number at most $H - 1 - k_N \le H - N$. By condition~(1), each unobserved hop advances execution by at most one window. Thus, the true start window satisfies $\sigma_0 \ge \sigma_{k_1} - k_1 \ge \min(\mathcal{E}) - (H - N)$, and true termination satisfies $\sigma_{H-1} \le \sigma_{k_N} + (H - 1 - k_N) \le \max(\mathcal{E}) + (H - N)$. The expanded evidence interval $[\min(\mathcal{E}) - \delta_s, \max(\mathcal{E}) + \delta_s]$ strictly contains $[\sigma_0, \sigma_{H-1}]$. Furthermore, because the realized execution $\sigma^*$ belongs to $\Sigma(p)$, Definition~\ref{eq:tac} guarantees $[\sigma_0, \sigma_{H-1}] \subseteq \text{TAC}(p)$ by topological validity. Their intersection $\text{FWoC}(p)$ therefore contains $[\sigma_0, \sigma_{H-1}]$. When condition~(1) is violated (dormancy gaps $> 1$ window), $\delta_s$ under-expands and containment may fail (Table~\ref{tab:dormant-apt}). $\square$

\paragraph{Structural Contradiction Detection.}
When the intersection in Equation~\ref{eq:fwoc} yields an empty set ($\text{FWoC}(p) = \emptyset$), the evidence timestamps are physically incompatible with the topological attack corridor under tolerance margin $\delta$. This contradiction flags false-positive alerts, falsified timestamps, or invalid path hypotheses. In practice, operational precision depends on calibrating $\delta$ against background timing noise. Operating at strict equality ($\delta=0$) flags unmodeled $\pm 1$-window clock skew on serial paths as false alarms (yielding precision 0.75), whereas setting $\delta \ge 1$ absorbs benign transit jitter to achieve 1.00 precision, with structural violations detected by construction (Table~\ref{tab:falsification}).

\subsection{Topological Triage \& Scoping}\label{sec:network-metrics}

While path metrics evaluate candidate routes, incidents across enterprise networks require prioritizing investigation resources. F-TAG aggregates surviving paths across the topology to compute structural triage metrics.

To pinpoint mandatory forensic chokepoints---hosts the adversary was forced to traverse regardless of the specific route---the temporal chokepoint score $\chi(h)$ measures the fraction of surviving attack paths traversing host $h$:
\begin{equation}\label{eq:chokepoint}
\chi(h) = \frac{|\{p \in \mathcal{P}_{surviving} : h \in V(p)\}|}{|\mathcal{P}_{surviving}|}
\end{equation}
where $\mathcal{P}_{surviving}$ denotes the set of candidate attack paths that remain valid after applying temporal and evidence constraints, and $V(p)$ is the set of hosts visited along path $p$. A score of $\chi(h) = 1.0$ confirms that host $h$ lies on every structurally plausible attack path.



To scope log retrieval, $T_{min}(j_{tgt})$ identifies the earliest time window an attacker could have first breached the network on any path reaching target asset $j_{tgt}$. Derived purely from topology, $T_{min}$ remains invariant under log deletion:
\begin{equation}\label{eq:tmin}
T_{min}(j_{tgt}) = \min_{p \in \mathcal{P}_{\to j_{tgt}}} \sigma_0(p)
\end{equation}
where $\mathcal{P}_{\to j_{tgt}}$ is the set of topologically feasible backward-reachable attack paths terminating at a downstream victim asset $j_{tgt}$ (such as a database exfiltration event), and $\sigma_0(p)$ is the initial entry execution time window of path $p$.

\subsection{Anti-Forensics Confidence (\texorpdfstring{$AF_{conf}$}{AF\_conf})}\label{sec:afconf}

When an attack path contains an unobserved hop, investigators must distinguish routine logging failure (log rotation, packet drops) from deliberate anti-forensic wiping. The Anti-Forensics Confidence metric ($AF_{conf}$) estimates the posterior probability of deliberate log-wiping given an evidence gap $G$ at node $n$ with acquired privilege level $x$:
\begin{equation}\label{eq:afconf}
AF_{conf}(G) = P(H_1 \mid x) = \frac{P(x \mid H_1)\,P(H_1)}{P(x \mid H_1)\,P(H_1) + P(x \mid H_0)\,P(H_0)}
\end{equation}
where:
\begin{itemize}
    \item $H_1$ is the hypothesis that the evidence was \textbf{deliberately wiped} by an attacker.
    \item $H_0$ is the hypothesis that the evidence was lost through \textbf{benign causes} (routine maintenance, logging failure).
    \item $P(H_1)$ and $P(H_0) = 1 - P(H_1)$ are prior probabilities reflecting baseline operational suspicion.
    \item $x \in \{\text{root}, \text{user}\}$ is the privilege state the attacker acquired on node $n$ (where ``root'' indicates full administrative access, and ``user'' indicates restricted, standard access).
\end{itemize}

The likelihood terms in Equation~\ref{eq:afconf} are grounded directly in operating system access-control principles. In modern operating systems, unprivileged users cannot modify or erase security event logs (such as Windows Security Event Logs, or endpoint detection telemetry), tampering with audit records strictly requires administrative or root privileges. Consequently, under the deliberate wiping hypothesis ($H_1$), the adversary is predominantly expected to have acquired root access:
\begin{equation}
P(\text{root} \mid H_1) = 0.75, \quad P(\text{user} \mid H_1) = 0.25
\end{equation}
These representative heuristic values reflect that log tampering predominantly requires administrative privileges (0.75), while retaining a non-zero probability (0.25) for edge cases such as user-space log deletion or lateral movement before privilege escalation. Grounding likelihood in access permissions provides robust discrimination without relying on brittle anti-forensic tool signatures that adversaries evade.

Conversely, benign logging failures (e.g., buffer overflows or network packet drops) happen indiscriminately across infrastructure regardless of host privilege. Under $H_0$, the probability of observing a missing record at a root-privileged node simply equals the empirical proportion of root nodes across the generated F-TAG:
\begin{equation}\label{eq:base-rate}
P(\text{root} \mid H_0) = P_{root,H_0} = \frac{|\{n \in V_{all} : \text{priv}(n) = \text{root}\}|}{|V_{all}|}
\end{equation}
Since F-TAG computes $P_{root,H_0}$ directly from the network topology under investigation, $AF_{conf}$ automatically calibrates itself to any environment (such as high-privilege server clusters versus locked-down workstation subnets). This formulation yields two analytical properties that govern the behavior of $AF_{conf}$.

\begin{lemma}[Monotonicity under Equal Base Rates]
If $P(x_{root} \mid H_0) = P(x_{user} \mid H_0)$ (i.e.\ the base rate of missing evidence is the same across privilege levels), then $AF_{conf}$ is strictly higher at root nodes than at user nodes.
\end{lemma}

\textit{Proof:} Let $c = P(x_{root} \mid H_0) = P(x_{user} \mid H_0)$. By our domain grounding, $P(x_{root} \mid H_1) = 0.75 > 0.25 = P(x_{user} \mid H_1)$. The posterior $AF_{conf}(x) = \frac{P(x \mid H_1) P(H_1)}{P(x \mid H_1) P(H_1) + c\, P(H_0)}$ is strictly increasing in $P(x \mid H_1)$ for fixed $c > 0$. Hence $AF_{conf}(x_{root}) > AF_{conf}(x_{user})$. Concretely, at a 10\% prior with $c = 0.5$ (half the nodes are root, i.e.\ truly uniform), this gives $\approx 14\%$ at a root node versus $\approx 5\%$ at a user node. $\square$

\textit{Note:} When $P(x_{root} \mid H_0) \neq P(x_{user} \mid H_0)$, the ordering depends on the specific base rates. The lemma's equal-base-rate condition is the sanity case; the general formula in Equation~\ref{eq:afconf} handles arbitrary base rates directly.

\textit{Boundary Condition (Root Saturation Inversion):} In networks saturated with root-privileged nodes ($P(x \mid H_0) \to 1$), the base rate for non-root nodes approaches zero ($P(x_{user} \mid H_0) \to 0$). Here, missing evidence at a rare non-root node produces an artificially high $AF_{conf}$ score, inverting the expected ordering.

\begin{lemma}[Root-Node Posterior Limit under Saturation]
As the network becomes saturated with root-level nodes ($P(x \mid H_0) \to 1$), the $AF_{conf}$ score for root nodes drops strictly below the prior $P(H_1)$.
\end{lemma}

\textit{Proof:} Let $P(x \mid H_0) \to 1$. With operational setting $P(x \mid H_1) = \alpha = 0.75$, the limit is $\frac{0.75 P(H_1)}{0.75 P(H_1) + P(H_0)}$. Since $P(H_1) < 1$ and $P(H_0) > 0$, this is strictly less than the prior $P(H_1)$. The limit only approaches $P(H_1)$ if we assume deliberate wiping \textit{always} occurs at root nodes ($\alpha \to 1$). $\square$

\paragraph{Sanity Properties of $AF_{conf}$.}
Together, Lemma~1 and Lemma~2 formally characterize $AF_{conf}$ under extreme baselines. Lemma~1 establishes the standard sanity property that root nodes are strictly prioritized when operational loss is privilege-blind. Lemma~2, along with the saturation inversion boundary condition, exposes the metric's limit under pathological baselines. In root-saturated networks, missing evidence at a rare non-root node scores near 1 ($P(x_{user} \mid H_0) \to 0$), causing false accusations of deliberate wiping to concentrate heavily on rare user-level nodes while deflating suspiciousness on the root nodes adversaries actually target.

\section{Evaluation}\label{sec:evaluation}

To evaluate F-TAG, its performance is assessed across two complementary environments.
\begin{itemize}
    \item \textbf{Historically Verified Intrusions (DARPA LLDOS 1.0 and 2.0.2)}~\cite{haines2001extending,darpa2000lldos}: Provides packet-level ground truth to test timeline reconstruction, FWoC bounds under evidence degradation, topological triage stability, and adversarial falsification detection.

\subsection{Bayesian Anti-Forensics Calibration (\texorpdfstring{$AF_{conf}$}{AF\_conf})}\label{sec:results-afconf}

The central operational question is whether $AF_{conf}$ can reliably tell deliberate log-wiping apart from routine telemetry loss, and whether that discrimination depends on how suspicious we start out (the prior $P(H_1)$).

To evaluate this, we calibrated $AF_{conf}$ using a Monte Carlo injection pipeline across 30 independent seeds and three prior settings ($P(H_1) \in \{0.05, 0.15, 0.30\}$) on the synthetic MulVAL F-TAG (900,900 total evaluation instances across 15 candidate paths; 30,030 samples per seed), testing three distinct evidence-loss classes:
\begin{enumerate}
    \item \textbf{Wipe-Class ($H_1$)}: Deliberate log-wiping biased toward high-privilege pivot nodes ($10\times$ weight for root status) and scaled by temporal chokepoint score $\chi$.
    \item \textbf{Random-Benign ($H_0$)}: Uniformly distributed evidence loss across all path nodes, modeling accidental failure.
    \item \textbf{Rotation-Benign ($H_0$)}: Periodic log loss recurring at fixed machines, modeling scheduled log rotation.
\end{enumerate}

\centering

\paragraph{It Does Not Depend on the Prior.}
Lemma~\ref{lemma:prior-invariance} proves that the ranking $AF_{conf}$ induces is strictly prior-invariant; Figure~\ref{fig:fwoc-afconf} illustrates the resulting ROC curve (AUC = 0.801 for Wipe vs. Random loss) and maps the discrete operating points induced by binary privilege.

\begin{lemma}[Prior Invariance of Ranking]\label{lemma:prior-invariance}
For fixed $x \in \{\text{root}, \text{user}\}$, the posterior 
\[ AF_{conf}(x) = \frac{P(x \mid H_1)P(H_1)}{P(x \mid H_1)P(H_1) + P(x \mid H_0)P(H_0)} \]
is a strictly increasing function of the likelihood ratio $LR(x) = \frac{P(x \mid H_1)}{P(x \mid H_0)}$ for any $P(H_1) \in (0,1)$. Since the set of achievable $LR$ values (and hence the induced ranking over samples) is independent of $P(H_1)$, the ROC curve, and therefore AUC, is invariant to the choice of prior.
\end{lemma}

\textit{Proof:} Write $AF_{conf}(x) = \frac{LR(x)P(H_1)}{LR(x)P(H_1) + (1-P(H_1))}$, which is strictly increasing in $LR(x)$ for any fixed $P(H_1) \in (0,1)$ since $\frac{\partial AF_{conf}}{\partial LR} = \frac{P(H_1)(1-P(H_1))}{(\cdot)^2} > 0$. As $LR(x)$ does not depend on $P(H_1)$, the ordering of $AF_{conf}$ across the two values of $x$ is preserved for every $P(H_1)$, so the ROC curve (which depends only on this ordering) is unchanged. $\square$

\textbf{Implication.} Like Lemmas 1--2, this sanity property confirms that the ranking induced by $AF_{conf}$ is structurally prior-invariant, meaning that varying $P(H_1)$ scales the numerical posteriors while preserving their monotonic ordering. With binary privilege metadata ($x \in \{\text{root}, \text{user}\}$), this simply guarantees that root nodes remain ordered ahead of user nodes for any valid prior. While an investigator can rely on this ordering for coarse binary triage without tuning $P(H_1)$, the resulting ROC curve (AUC $\approx 0.801$) reflects this fixed two-level partition rather than continuous discrimination.

\paragraph{Operating Points and Step-Function Threshold Behavior.}
Under the binary privilege formulation with operational prior $P(H_1) = 0.15$, $AF_{conf}$ evaluates to exactly two discrete score levels, namely $0.0475$ for unprivileged nodes and $0.5323$ for root/administrative nodes. Because of this binary structure, threshold behavior is a step function rather than a continuous curve, as detailed in Table~\ref{tab:far}. At threshold $0.50$, all root nodes are flagged (496,279 samples across 30 seeds), achieving 0.773 precision, 0.852 recall, and 0.810 F1, while incurring a false-accusation rate (FAR) of 25.0\% against random benign loss (25.4\% against rotation loss). For any threshold above $0.5323$—including 0.70, 0.85, and 0.90—the classifier flags exactly zero alerts. Thus, the previously observed 0.0\% FAR at threshold 0.85 is an artifact of complete classification silence ($\text{Recall} = 0.0\%$), rather than high-confidence discrimination. In practice, operational alerting requires either calibrating the baseline prior $P(H_1)$ to shift the discrete score levels or incorporating multi-tier privilege models.

\paragraph{Privilege Bias Circularity and Limitations.}
To test whether the headline discrimination ($\text{AUC} \approx 0.801$) is driven by F-TAG's structural modeling or circular dependence on the wipe generator's privilege bias, we swept the wipe generator's root-node selection weight across $1\times, 2\times, 5\times$, and $10\times$ (30 seeds, 900,900 samples total, Table~\ref{tab:root-sweep}). When the generator exhibits no privilege bias ($1\times$), AUC collapses to $0.5574$ (95\% CI: [0.5566, 0.5583]), barely above random chance. As root targeting bias increases to $2\times$, $5\times$, and $10\times$, the mean AUC rises monotonically to $0.6421$, $0.7459$, and $0.8007$, respectively. This demonstrates that $AF_{conf}$'s discriminative power strictly tracks the attacker's own privilege targeting bias rather than an independent structural signal. We report this honestly as a fundamental limitation of binary privilege metadata; when an attacker wipes logs uniformly without privilege preference, $AF_{conf}$ cannot separate deliberate wiping from accidental loss. Addressing this requires privilege-agnostic loss models (e.g., volumetric anomaly detection and telemetry continuity checks) in future work.

Table~\ref{tab:scalability} reports computational scalability, separating proactive offline generation (6.5--21.2\,s for 99 hosts) from online reactive triage. For the 99-host, 2,177-edge network (corrected from 2,179 in preliminary drafts), Algorithm~\ref{alg:enumerate} enumerates all 8,320 candidate temporal paths in 7.5\,ms and evaluates metrics in 2.8\,ms (10.3--12.8\,ms total). Importantly, the absence of a $22^5$ path explosion at $H_{max} \ge 3$ is a structural property of the synthetic generator. It models strict DMZ $\to$ App $\to$ Database progression where inter-tier ACLs render all simple ingress-to-target paths exactly 3 hops, so setting $H_{max}=5$ (or 15) explores the exact same 8,320 paths in 11.4\,ms enumeration (14.3\,ms total triage). Real enterprise networks, however, feature peer-to-peer lateral movement within subnets. To test this boundary, we injected intra-tier lateral edges within the DMZ and Application tiers; at $H_{max}=5$, candidate paths expand moderately from 8,320 to 13,223, enumerating in 14.9\,ms. In dense, unpartitioned mesh topologies with unconstrained cycles, paths scale with $O(k_{max}^{H_{max}})$; there, bounding $H_{max} \le 5$ and applying standard subnet decomposition (Section~\ref{sec:threats}) is required to maintain real-time triage.

\section{Discussion and Threats to Validity}\label{sec:discussion}\label{sec:threats}

By injecting evidence as strict filters over time-varying topologies, F-TAG eliminates static attack graphs' structural failure modes while sustaining real-time triage ($O(|\mathcal{P}_{surviving}| \cdot H_{max})$, under 15\,ms for 99 hosts). However, F-TAG operates within four boundaries. First, $AF_{conf}$ thresholds were calibrated on synthetic MulVAL graphs; evaluating them against live SIEM telemetry with verified anti-forensic ground truth is the next step. Second, the binary privilege model serves as a baseline floor; richer privilege hierarchies (SELinux, AD) will expand discrimination. Third, dense topologies benefit from subnet aggregation to sustain real-time triage at enterprise scale. Finally, F-TAG treats configuration snapshots and vulnerability scans as tamper-resistant ground truth. If scan data originates from infrastructure already controlled by an adversary, the reference frame itself is compromised---a trust boundary common to all attack graphs.

\paragraph{Adversarial Dormancy Boundary.}\label{sec:adversarial-dormancy} Table~\ref{tab:dormant-apt} stress-tests FWoC against a simulated dormant APT with an 18-window gap between reconnaissance and exploitation, violating the contiguous-execution assumption. \section{Conclusion and Future Work}\label{sec:conclusion}
We introduced F-TAG, a retrospective forensic model that constrains attack sequence reconstruction using time-varying network topologies. We derived the Forensic Window of Compromise (FWoC) to bound unobserved actions under contiguous execution, characterized its breakdown under adversarial dormancy, and derived $AF_{conf}$ via Bayesian inference to quantify deliberate log wiping while identifying its privilege-bias boundary. On DARPA LLDOS benchmarks, F-TAG detected structural falsifications that static attack graphs miss, while identifying single-path redundancy as an operational boundary. Future work will explore multi-level privilege models (e.g., SELinux) and telemetry continuity checks to address privilege-bias circularity. While bound correctness and evidence-driven narrowing were validated here (compressing a 13-window corridor to $8.39 \pm 0.04$ at $N=1$ and to the exact 5.00-window breach at $N=5$ under $H \ll \tau$), extending F-TAG to continuous sliding windows and live SIEM telemetry remains the natural next step toward operational deployment.
